# ThreadGrade — Quest EYP Prototype

A static, interactive concept prototype demonstrating the ThreadGrade workflow described in the Quest EYP presentation:

- Overview dashboard with sample metrics and recent lots
- Simulated AI pre-sort and grade proposal
- Human confirmation and weighted custom-vs-bulk routing
- Lot passport with a QR link and JSON download
- Buyer lane pricing and routing score calculator
- Illustrative lot-backed finance estimator

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or run a local static server from this directory:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to Vercel

1. Create a GitHub repository and upload all files in this folder (`index.html`, `styles.css`, `app.js`, `vercel.json`, and this README).
2. In Vercel, choose **Add New → Project** and import that repository.
3. Framework preset: **Other**. Build command: leave blank. Output directory: `.` (or leave the default for a static project).
4. Deploy. Vercel will provide a public `https://...vercel.app` URL.
5. Open the deployed site on your phone and test the workflow. The QR on a lot passport points to the deployed site's lot URL. The QR image is generated by an external QR-code service, so internet access is needed to display it.
6. Create a QR code for the public homepage URL for your slide using a QR generator, then scan-test it from another device before submitting.

## Prototype boundaries

All dashboard metrics, grade proposals, prices, score calculations, finance estimates, and transaction records are illustrative demo data. There is no connected AI model, fibre analyser/NIR device, real buyer auction, database, login, lender integration, or independently certified test result. The UI labels these boundaries. A production version would require validated grading methods, secure backend storage, authentication, audit logs, and partner integrations.
